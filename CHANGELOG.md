# Changelog

All notable changes to warble-army are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/). From the first release on, entries
are generated by release-please from Conventional Commit titles
(see [docs/RELEASING.md](docs/RELEASING.md)). Starling Lite has its own log in
[mcp/starling-lite/CHANGELOG.md](mcp/starling-lite/CHANGELOG.md).

## [Unreleased]

### Added
- Issue forms (bug, feature, security redirect), PR template, CODEOWNERS, Dependabot.
- DCO sign-off policy and `dco` check.
- OpenSSF Scorecard workflow and README badge.
- Label taxonomy (`.github/labels.yml`, `docs/LABELS.md`).
- Release process (release-please, manual trigger for now).

### Changed
- `check.yml` is fork-friendly: private-submodule/PAT steps are optional and
  forks / fork PRs run on GitHub-hosted runners.
