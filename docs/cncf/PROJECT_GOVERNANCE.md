# Project governance — Starling EX Community (seed)

Lightweight governance for the open flock until CNCF processes apply.

## Roles

- **Contributors** — anyone with a merged PR or meaningful issue work.  
- **Maintainers** — listed in [MAINTAINERS.md](MAINTAINERS.md); merge rights and release authority.  
- **Steward (interim)** — ChirpStack LLP / Warble Cloud until CNCF donation completes.

## Decisions

- Day-to-day: maintainers of the affected repo.  
- Cross-repo / roadmap: lazy consensus among maintainers; document in issues/RFCs.  
- Security releases: SECURITY process takes priority.

## Changes to governance

PR against this file; require approval from a majority of maintainers.

## After CNCF Sandbox acceptance

This document yields to CNCF project governance templates and charter updates required during onboarding.
